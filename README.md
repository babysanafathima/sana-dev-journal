# SANA.DEV Journal

### A Personal Developer Publication

SANA.DEV Journal is a personal development journal built to document my journey into frontend development, share technical knowledge, and explore the ideas behind building modern web applications.

Designed with an editorial-inspired aesthetic, the journal combines a clean reading experience with carefully structured articles covering React, JavaScript, CSS, and software development.

## Overview

The project reflects my learning journey as a frontend developer and serves as a space to document concepts, share practical insights, and continuously improve my technical understanding.

## Features

- **Editorial Design** — A refined reading experience with a warm, publication-inspired visual style.
- **Article Collection** — Technical articles covering frontend development and programming.
- **Category Filtering** — Explore articles by development topics.
- **Individual Article Pages** — Dedicated reading layouts for each article.
- **Responsive Layout** — Adapted for desktop, tablet, and mobile screens.
- **Interactive Navigation** — Smooth navigation between sections and articles.
- **Contact Integration** — Direct email contact through the navigation and footer.

## Topics Covered

- React.js
- JavaScript
- CSS and Responsive Web Design
- Frontend Development
- Developer Mindset and Learning

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/babysanafathima/sana-dev-journal.git
   ```

2. Navigate into the project directory:

   ```bash
   cd sana-dev-journal
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
